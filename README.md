# InterviewAI – Practice Technical & HR Mock Interviews

> **"Practice tech & HR interviews before the real thing."**

A clean, simple mock interview practice web application built with **HTML5 and CSS3**. Designed to be lightweight, human-crafted, and easy to run right in the browser.

---

## 🌟 Highlights

- **Single-Page Simplicity**: The entire application is cleanly organized in `index.html` with a streamlined stylesheet in `css/style.css`.
- **Live Mock Interview Room**: Realistic interview stage with an interviewer tile, candidate preview, live countdown timer, and an active question prompt.
- **Structured Answering Helpers**: Expandable hint accordions (`<details>`) outlining the exact framework to structure answers.
- **Sample Scorecard & Honest Rubric**: Realistic feedback breakdown covering Technical Accuracy, Structure & Flow, and Completeness, with constructive bullet points and a model answer.
- **Curated Question Bank**: Real, frequently asked questions covering Frontend (JS closures, Virtual DOM), Backend (SQL vs NoSQL, REST PUT vs PATCH), and HR/Behavioral questions (STAR method).
- **Practical Interview Tips**: 4 essential rules for students and job seekers on interview day.
- **Zero JavaScript & Zero External Frameworks**: 100% accessible HTML5 and CSS3.

## 🚀 Running Locally

Open `index.html` directly in any web browser, or start a local server using Python:

```bash
# Clone the repository
git clone https://github.com/ayushmaanshukla20-source/ai-interviewer_individual-project.git

# Navigate to the folder
cd ai-interviewer_individual-project

# Start a local static server
python -m http.server 3000
```
Then visit **`http://localhost:3000`** in your browser.
