Web Fundamentals Intermediate

"Walk me through what happens step-by-step when you type google.com into your browser and press Enter."

💡 Need a tip on structuring this answer? (Click to view)
Key Steps to Mention:
  1. DNS Lookup: Browser checks cache (browser, OS, router) then queries DNS servers to resolve the domain to an IP address.
  2. TCP Handshake: Browser initiates a 3-way handshake (SYN, SYN-ACK, ACK) to establish a connection with the server.
  3. TLS Handshake: For HTTPS, certificates and encryption keys are exchanged.
  4. HTTP Request & Response: Browser sends GET request; server responds with HTML, status codes (e.g. 200 OK), and headers.
  5. Browser Rendering: HTML is parsed to DOM, CSS to CSSOM, combined into Render Tree, followed by Layout and Paint.

Ideal 60-Second Answer:

"When you enter a URL, the browser first resolves the hostname into an IP address via DNS lookup, checking local browser caches, OS resolver, and root DNS servers. Next, the client establishes a reliable TCP connection with the server via a three-way handshake (SYN, SYN-ACK, ACK), followed by a TLS handshake for HTTPS security. The browser then dispatches an HTTP GET request. The web server processes the request and returns an HTTP response containing headers and the HTML payload. Finally, the browser parses the HTML into a DOM tree, parses CSS into a CSSOM tree, combines them into a Render tree, calculates geometry during the layout phase, and paints pixels onto the screen."

Frontend Beginner
What is the difference between let, const, and var in JavaScript?
Reveal Sample Answer

Answer:

  • var: Function-scoped, can be re-declared and re-assigned, and is hoisted with an initial value of undefined.
  • let: Block-scoped, can be re-assigned but not re-declared in the same scope. Hoisted into the Temporal Dead Zone (cannot access before initialization).
  • const: Block-scoped, cannot be re-assigned or re-declared, and must be initialized when declared. (Note: objects declared with const can still have their properties mutated).

💡 Rule of thumb: Default to const, use let when a value needs reassignment, avoid var in modern code.

Frontend Intermediate
What is the Virtual DOM and how does React reconciliation work?
Reveal Sample Answer

Answer: The Virtual DOM is a lightweight, in-memory JavaScript representation of the real DOM. When state changes, React creates a new Virtual DOM tree and runs a diffing algorithm (reconciliation) comparing it to the previous tree. It determines the minimum set of real DOM updates required and batches them efficiently, avoiding slow browser re-paints.

Backend / DBMS Intermediate
When should you choose a SQL database over a NoSQL database?
Reveal Sample Answer

Answer: Choose SQL (PostgreSQL, MySQL) when your data is structured, relationships between entities are clear, and you require strict ACID compliance (e.g. banking, e-commerce orders). Choose NoSQL (MongoDB, DynamoDB) when handling rapidly evolving schemas, large-scale unstructured document data, or when horizontal scaling across distributed nodes is prioritized over complex relational joins.

Backend / APIs Beginner
What is the difference between PUT and PATCH in REST APIs?
Reveal Sample Answer

Answer: PUT replaces the entire resource with the payload sent in the request (idempotent complete update). PATCH applies partial modifications to an existing resource, only updating the specific fields provided.

HR / Intro Universal
"Tell me about yourself" (How to answer in under 90 seconds)
Reveal Sample Answer & Framework

Use the Present-Past-Future Model:

1. Present: Who you are right now and your current focus ("I'm a final-year student specializing in full-stack web development with React and Node.js...").

2. Past: Relevant projects or internships with measurable impact ("Recently, I built a collaborative task app that cut response times by 30%...").

3. Future: Why you are excited about this specific role ("I want to join your team to contribute to scalable web applications and learn from experienced engineers.").

Behavioral Intermediate
"Describe a difficult challenge or bug you faced in a project and how you resolved it."
Reveal Sample Answer (STAR Method)

Use the STAR Method:

  • Situation: Describe the context (e.g., our college portal crashed under heavy test load).
  • Task: What was your goal? (Diagnose the bottleneck and fix it before deployment).
  • Action: What did YOU do? (Used Chrome DevTools profiler, identified an un-indexed database query causing memory spikes, added index and memoized data).
  • Result: What was the outcome? (Reduced load time from 4.2s to 600ms with zero crashes).
4 Practical Tips for Interview Day

Simple, proven advice to remember when answering technical and HR questions.

1. Think Out Loud

Interviewers care more about how you reason through a problem than whether you memorize exact syntax. Speak your assumptions and trade-offs as you write.

2. Structure with the STAR Method

For behavioral questions, stick to Situation, Task, Action, Result. It keeps you focused on your individual contribution and prevents rambling.

3. Ask Clarifying Questions First

Never start coding immediately. Clarify edge cases: "Can input numbers be negative?", "How large can the array be?", or "Are inputs guaranteed to be valid?".

4. Prepare Questions for the Interviewer

At the end, always ask 1–2 thoughtful questions: "What does the typical onboarding process look like?" or "What is the biggest technical challenge your team tackled recently?".
