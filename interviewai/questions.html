🌐 HTML, CSS & Modern JavaScript

Frontend Track
JavaScript Runtime Intermediate
Topic: Asynchronous Programming

Explain the JavaScript Event Loop and differentiate between the Microtask queue and Macrotask queue.

🔍 Reveal Model Answer & Strategy

Model Answer:

JavaScript is a single-threaded runtime with a synchronous Call Stack. Long-running or async tasks are delegated to browser/Node APIs. When async tasks complete, their callbacks are placed in queues:

  • Microtask Queue: Holds callbacks from Promises, queueMicrotask(), and MutationObserver. Microtasks execute immediately after the current stack frame empties.
  • Macrotask Queue (Task Queue): Holds callbacks from setTimeout, setInterval, and I/O events.
  • The Event Loop Rule: The event loop drains the entire microtask queue before picking the next single macrotask from the task queue.
💡 Answering Tip: Mention that an infinite microtask loop (e.g. recursive Promise chaining) will starve macrotasks and freeze UI rendering.
CSS Layout Beginner
Topic: Responsive Design

When should you choose CSS Grid over Flexbox, and how do their dimension models differ?

🔍 Reveal Model Answer & Strategy

Model Answer:

Flexbox is a one-dimensional layout system designed for distributing space along either a row or a column (content-first). It excels at navigation bars, button groups, and vertical centering.

CSS Grid is a two-dimensional layout system designed for strict row and column alignment simultaneously (layout-first). It excels at page templates, dashboards, photo galleries, and complex multi-column responsive systems.

💡 Answering Tip: State clearly: "Flexbox is 1D (row OR column), while Grid is 2D (rows AND columns simultaneously)."

☕ Java & Python Core Concepts

Backend Track
Java JVM Intermediate
Topic: Memory & Garbage Collection

How does Garbage Collection operate in the Java Virtual Machine (JVM), and what are Generational Heaps?

🔍 Reveal Model Answer & Strategy

Model Answer:

The JVM manages memory automatically by reclaiming objects that are no longer reachable from GC Roots (threads, static variables, local stack variables). The JVM heap is partitioned into generations based on the weak generational hypothesis (most objects die young):

  • Young Generation: Divided into Eden and Survivor spaces (S0, S1). Fast Minor GC cleans short-lived objects.
  • Old (Tenured) Generation: Holds surviving objects promoted after threshold cycles. Collected via Major/Full GC (e.g., G1, ZGC).
💡 Answering Tip: Mention modern GC algorithms like G1GC or ZGC which focus on ultra-low stop-the-world pause times.
Python Internals Intermediate
Topic: Concurrency & GIL

What is Python's Global Interpreter Lock (GIL), and how do you achieve true parallel execution?

🔍 Reveal Model Answer & Strategy

Model Answer:

The Global Interpreter Lock (GIL) is a mutex in CPython that prevents multiple native threads from executing Python bytecodes simultaneously, safeguarding CPython's reference-counting memory management.

To overcome this: for I/O-bound tasks, threading or asyncio provides high concurrency because the GIL is released during I/O. For CPU-bound tasks, developers use multiprocessing, which spawns independent OS processes each with their own memory and GIL.

💾 Data Structures, DBMS, OS & Networks

Fundamental CS
Database Systems Intermediate
Topic: Indexing & Storage Engine

Why are B+ Trees predominantly used for relational database indexes instead of Hash Tables or Binary Search Trees?

🔍 Reveal Model Answer & Strategy

Model Answer:

B+ Trees provide significant advantages for persistent disk-based storage engines:

  • Range Queries: Leaf nodes in a B+ Tree are linked in a sequential doubly-linked list, allowing O(log N) point lookup followed by fast O(K) linear range scanning (unlike Hash Tables which only do O(1) equality).
  • High Fan-Out & Low Height: B+ Tree nodes fit into standard OS disk pages (e.g. 4KB/16KB), drastically reducing disk I/O seeks compared to deep Binary Search Trees.
Operating Systems Beginner
Topic: Process Management

Explain the difference between a Process and a Thread, and what resources are shared.

🔍 Reveal Model Answer & Strategy

Model Answer:

A Process is an executing instance of a program with its own isolated address space (text, data, heap, file descriptors). Context switching between processes is relatively expensive.

A Thread is the smallest schedulable unit of execution within a process. Threads within the same process share the heap, global variables, and open files, but maintain their own program counter (PC), registers, and stack frame.

🤖 Artificial Intelligence & Machine Learning

AI Engineer Track
Transformers & NLP Advanced
Topic: Attention Mechanism

How does the Multi-Head Self-Attention mechanism in the Transformer architecture work mathematically?

🔍 Reveal Model Answer & Strategy

Model Answer:

Self-attention maps input representations into Query (Q), Key (K), and Value (V) matrices via learned linear projections. The attention weights are calculated via Scaled Dot-Product Attention: Attention(Q, K, V) = softmax(Q * K^T / sqrt(d_k)) * V.

Multi-Head Attention projects Q, K, and V into h distinct lower-dimensional subspaces, computes attention in parallel for each head, and concatenates the results before a final linear projection, enabling the model to attend to information from different representation subspaces at different positions.

Leadership & Teamwork
Conflict Resolution Intermediate

"Describe a situation where you had a strong disagreement with a teammate or lead regarding a technical decision. How did you resolve it?"

🔍 Reveal Model Answer & Strategy

Structured STAR Response:

Situation: While building our capstone project, my team lead wanted to use a NoSQL document database, whereas I advocated for PostgreSQL due to strong relational transactions in our billing module.

Task: We needed to decide before our sprint deadline without causing friction or architectural paralysis.

Action: Rather than arguing opinions, I created a quick benchmark prototype of our 3 most critical query patterns and presented an objective matrix comparing schema migration overhead and query speeds.

Result: We agreed to use PostgreSQL for transactions and Redis for session caching, which helped us ship on time with zero schema inconsistencies.

💡 Answering Tip: Always highlight data-driven resolution and psychological safety over "winning the argument".
