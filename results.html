Q1 Explain the JavaScript Event Loop, Microtasks vs Macrotasks.
Score: 92 / 100 ▼
Your Submitted Answer:
"The JavaScript engine is single-threaded and relies on the Event Loop to handle asynchronous operations. The Call Stack handles synchronous execution. When asynchronous operations resolve, their callbacks are queued into either the microtask queue or macrotask queue. Microtasks, such as Promise then/catch handlers and queueMicrotask, have higher priority and are completely drained after the current stack frame finishes, before the event loop picks up the next macrotask (such as setTimeout or setInterval callbacks)."
Automated Evaluation & Feedback:
Strengths: Spot-on explanation of the call stack role, accurate prioritization of microtasks over macrotasks, and clear definition of queue exhaustion.

Q2 Virtual DOM and React reconciliation algorithm mechanics.
Score: 88 / 100 ▼
Your Submitted Answer:
"The Virtual DOM is an in-memory lightweight JavaScript object representation of the real DOM tree. Reconciliation is React's heuristic O(N) diffing algorithm that compares previous and current Virtual DOM trees. Using stable keys on list elements, it calculates the minimal real DOM mutations required instead of re-rendering the whole page."
Automated Evaluation:
Strengths: Clear differentiation of in-memory representations and accurate O(N) complexity heuristics.
